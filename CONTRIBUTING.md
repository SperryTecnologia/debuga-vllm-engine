# Contribuindo com debuga.ai vLLM Engine

Obrigado pelo interesse em melhorar este componente público do ecossistema debuga.ai.

## Escopo aceito

- correções de documentação e exemplos;
- melhoria de validações, testes e mensagens de erro;
- correções de segurança com descrição responsável;
- ajustes de compatibilidade que preservem o escopo público do projeto.

## Antes de abrir um pull request

1. Abra uma issue descrevendo o problema ou a proposta.
2. Não inclua credenciais, dados reais de clientes, IPs internos ou material proprietário.
3. Mantenha exemplos reproduzíveis e identifique claramente qualquer resultado de laboratório.
4. Atualize a documentação quando o comportamento público mudar.
5. Execute as validações indicadas no README.

## Padrão de commits

Exemplos:

```text
docs: corrige quick start
fix: trata timeout do provider
test: cobre fallback do gateway
chore: atualiza exemplo de configuração
```

## Segurança

Não publique vulnerabilidades exploráveis em uma issue pública. Consulte [SECURITY.md](SECURITY.md).
